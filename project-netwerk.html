Netwerk configureren

Wat is dit project?

Voor dit project heb ik een kleinschalig netwerk opgezet met VLAN's, routing en DHCP.

Wat heb ik gedaan?

Ik heb het netwerk opgedeeld in VLAN's, de routing tussen die netwerken ingesteld en DHCP geconfigureerd zodat toestellen automatisch een IP-adres krijgen.

Wat heb ik geleerd?

Ik heb geleerd hoe je een netwerk opdeelt en hoe verkeer tussen verschillende netwerken loopt.
