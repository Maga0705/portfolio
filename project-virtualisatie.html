Virtualisatie met VM's

Wat is dit project?

Voor dit project heb ik meerdere virtuele machines opgezet op Proxmox om te testen en te leren.

Wat heb ik gedaan?

Ik heb op Proxmox verschillende virtuele machines aangemaakt. Zo kan ik nieuwe systemen uitproberen zonder mijn eigen computer of netwerk te riskeren.

Wat heb ik geleerd?

Ik heb geleerd hoe virtualisatie werkt en hoe je met één fysieke machine meerdere systemen kan draaien.
